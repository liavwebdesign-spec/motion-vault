דיוקן גבוה של בעלת העסק בצד אחד, ובצד השני היכרות קצרה בשמה, ההבטחה, כפתור לשיחת היכרות ושורה של שלוש עובדות. על הדיוקן תווית קטנה של זמינות.

מתי משתמשים: עסק שהוא אדם אחד: יועצת, מאמן, מטפלת, סטייליסטית, עורך דין, צלם, מרצה. הלקוח קונה את האדם, ולכן הפנים במסך הראשון ובגדול. לא בלי צילום מקצועי אמיתי של האדם, ולא לעסק עם צוות, שם h16 או h3.

פנויה לשתי לקוחות חדשות בנובמבר

כשהעסק הוא אדם אחד, הפנים הם ההוכחה הראשונה, ולכן הדיוקן גדול ובמסך הראשון. השורה הראשונה היא היכרות בקול שלה ובפונט התצוגה, וה-h3 שמתחתיה הוא ההבטחה, כך שהכותרת עדיין אומרת מה מקבלים ולא רק מי זאת. שלוש העובדות הן מספרים עם מילים (שנים, ארונות, משך המפגש) ולא מספור, ואין בהן כרטיסים או קווים. הדיוקן בצורת קשת למעלה, והוא נחשף מלמטה למעלה עם זום עדין; על הדיוקן תווית זמינות, שהיא עובדה ולא קישוט (הנקודה בצבע המותג, בלי הבהוב). בטלפון הדיוקן הופך לרצועה למעלה, עם הפנים במרכז החיתוך, ושני הכפתורים חולקים שורה. פתיחת העמוד (motion.md 2): ההירו מוסתר רק מאחורי html.open-anim, שהשורה הראשונה במארקאפ קובעת רק כשתנועה מותרת (בפרויקט היא עוברת ל-head). בלי JS הכל גלוי, ואם הסקריפט לא רץ ה-CSS מציג הכל אחרי 2.5 שניות. בעמוד עם הדר קובעים --t0 של 0.2 שניות כדי שההדר ייכנס ראשון, ומקצרים כך שהפתיחה כולה לא עוברת 1.2 שניות. המסך הראשון בפרויקט: min-height:100svh, תוכן ממורכז לגובה וריפוד עליון בגובה ההדר; hero-fit ו-hero-vcenter מכריעים, לא הגובה של הדמו.

קוד להדבקה

הקוד כאן עומד בפני עצמו. כל טוקן עיצוב נושא ברירת מחדל, מחלקות העזר של המאגר מוטמעות בו, ותגי הסקריפט מסודרים לפי הסדר הנכון. פרויקט שמגדיר --accent או --line משלו יורש אותם אוטומטית. הרכיב הזה מסתמך על dir="rtl".

JS

// in view = fire. Measured directly on scroll and resize, not through IntersectionObserver:
// an observer does not update while the tab is throttled (and on a real site the hero is usually
// on screen at load anyway), and an entrance that never fires leaves the hero invisible.
function inView(el,f){
  var ro;
  function chk(){
    var r=el.getBoundingClientRect();
    if(r.top<innerHeight*.9&&r.bottom>0){off();f();}
  }
  function off(){removeEventListener("scroll",chk);removeEventListener("resize",chk);if(ro)ro.disconnect();}
  addEventListener("scroll",chk,{passive:true}); addEventListener("resize",chk);
  // a layout change with no scroll (a bar above it closes, a font swaps in) can also bring it into view
  if(window.ResizeObserver){ro=new ResizeObserver(chk);ro.observe(document.body);}
  requestAnimationFrame(chk); setTimeout(chk,300);
}
function enter(root){
  var els=root.querySelectorAll(".rv");
  els.forEach(function(el,i){if(!el.style.getPropertyValue("--i"))el.style.setProperty("--i",i);});
  // a script that ran late, after the 2.5s CSS failsafe already showed the hero: keep it shown, no second entrance
  if(els.length&&getComputedStyle(els[0]).opacity==="1")root.classList.add("is-in");
  root.classList.add("rv-on");
  inView(root,function(){root.classList.add("is-in");});
}
