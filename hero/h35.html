H35 · הירו מצגת עם וילון בכיוון הקריאה וכותרת לכל תמונה

הירו CSS clip-path · JS הירו ופתיחהתמונות וגלריות ממתין

שלוש תמונות במסך מלא. כל תמונה חדשה נכנסת כמו וילון שנמשך מהצד שבו מתחילים לקרוא, מעל הקודמת, עם זום איטי החוצה. הכותרת מתחלפת יחד איתה: השורות של הישנה יוצאות למעלה, והחדשות עולות מלמטה שורה אחרי שורה. חצים, מונה, פס זמן וכפתור עצירה בפינה.

מתי משתמשים: עסק שהמקום שלו הוא המוצר, ולכל צילום יש משפט משלו: גלמפינג, צימר, וילה, מסעדה עם כמה חללים, אולם. מתאים כשרוצים שכל תמונה תספר חלק אחר מהחוויה. כשהמסר אחד והתמונות רק מראות את המקום מכמה זוויות, h15 עדיף: הכותרת שם קבועה ונקראת פעם אחת. לא עם פחות משלוש תמונות טובות.

שחזור. השראה: animtd.store (26.10.2026), סרטון של מצגת הירו שבה כל תמונה נכנסת בווילון והכותרת מתחלפת איתה. נבנה מאפס מהצפייה. במה זה שונה ממה שיש: ב-h15 התמונות מתחלפות בהתמזגות, והכותרת קבועה, כך שהמסר נקרא פעם אחת. כאן כל תמונה נכנסת בווילון (clip-path מ-inset מלא ל-0) מהצד שבו מתחילים לקרוא, ולכל תמונה יש כותרת משלה, שהשורות שלה עולות מתוך מסכה אחת אחרי השנייה. כשהמסר אחד, h15; כשכל תמונה מספרת חלק אחר, זה. הווילון: החדשה מקבלת z-index מעל ומעבר של 1.1 שניות; הקודמת נשארת שלמה מתחתיה עד הסוף ואז יורדת בלי מעבר, כך שבאמצע אף פעם לא רואים רקע. הכיוון הוא משתנה אחד (--off), ו-LTR מהפך אותו. בכניסה התמונה הנחשפת מתחילה מוגדלת ב-8% ונרגעת. הכותרות יושבות באותו תא של גריד, ולכן הגובה הוא של הארוכה וכלום לא קופץ; היוצאת עולה החוצה, הנכנסת עולה פנימה עם השהיה של רבע שנייה, ומי שלא בתמונה מוסתרת. השעון הוא פס הזמן: אנימציית CSS של 6 שניות ש-animationend שלה מביא את הבאה, כמו ב-h15, כך שעצירה, יציאה מהמסך ומיקוד מקלדת בפקדים עוצרים אותו בלי טיימר מקביל. נעילה של 1.15 שניות מונעת שלוש תמונות באמצע מעבר. נגישות: התמונות דקורטיביות, הכותרת היא הטקסט; הכותרות שלא מוצגות aria-hidden, וההכרזה (aria-live) נפתחת רק אחרי לחיצה על חץ, כדי שהחלפה אוטומטית לא תדבר כל 6 שניות. הפחתת תנועה: בלי החלפה לבד, בלי זום, והחלפה בחצים מיידית. פתיחת העמוד (motion.md 2): ההירו מוסתר רק מאחורי html.open-anim, שהשורה הראשונה במארקאפ קובעת רק כשתנועה מותרת (בפרויקט היא עוברת ל-head). בלי JS הכל גלוי, ואם הסקריפט לא רץ ה-CSS מציג הכל אחרי 2.5 שניות. בעמוד עם הדר קובעים --t0 של 0.2 שניות כדי שההדר ייכנס ראשון, ומקצרים כך שהפתיחה כולה לא עוברת 1.2 שניות. המסך הראשון בפרויקט: min-height:100svh, תוכן ממורכז לגובה וריפוד עליון בגובה ההדר; hero-fit ו-hero-vcenter מכריעים, לא הגובה של הדמו.

// in view = fire. Measured directly on scroll and resize, not through IntersectionObserver:
// an observer does not update while the tab is throttled (and on a real site the hero is usually
// on screen at load anyway), and an entrance that never fires leaves the hero invisible.
function inView(el,f){
  var ro;
  function chk(){
    var r=el.getBoundingClientRect();
    if(r.top<innerHeight*.9&&r.bottom>0){off();f();}
  }
  function off(){removeEventListener("scroll",chk);removeEventListener("resize",chk);if(ro)ro.disconnect();}
  addEventListener("scroll",chk,{passive:true}); addEventListener("resize",chk);
  // a layout change with no scroll (a bar above it closes, a font swaps in) can also bring it into view
  if(window.ResizeObserver){ro=new ResizeObserver(chk);ro.observe(document.body);}
  requestAnimationFrame(chk); setTimeout(chk,300);
}
