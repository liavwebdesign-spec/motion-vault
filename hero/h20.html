מול היםמול הים

השם הוא הלוגו, לא הכותרת: המשפט למעלה הוא ה-h3 (ובפרויקט ה-h1), עליו חל כלל 8% מגובה המסך, והשם הענק הוא p עם טקסט מלא לקורא מסך, ואותיות מפוצלות שמוסתרות ממנו (aria-hidden) כדי שלא ייקרא אות אחרי אות. הגודל שלו לפי הקטן מבין הרוחב והגובה (min של vw ו-vh), כך שבמסך נמוך הוא לא דוחף את המשפט החוצה, והוא יושב על הקצה התחתון עם שוליים שליליים קטנים, כמו שלט. האותיות עולות בהפרש של 50 מילישניות. יש שתי שכבות קריאות: אלכסונית מהפינה של המשפט, ורדיאלית מהמרכז התחתון מתחת לשם, כי הוא ממורכז (התורה). עובד עם שם של עד שבע אותיות; שם ארוך יותר יוצא קטן מדי והרעיון הולך לאיבוד. פונט התצוגה (Bellefair) הוא דוגמה: בפרויקט נכנס הפונט של הלוגו. פתיחת העמוד (motion.md 2): ההירו מוסתר רק מאחורי html.open-anim, שהשורה הראשונה במארקאפ קובעת רק כשתנועה מותרת (בפרויקט היא עוברת ל-head). בלי JS הכל גלוי, ואם הסקריפט לא רץ ה-CSS מציג הכל אחרי 2.5 שניות. בעמוד עם הדר קובעים --t0 של 0.2 שניות כדי שההדר ייכנס ראשון, ומקצרים כך שהפתיחה כולה לא עוברת 1.2 שניות. המסך הראשון בפרויקט: min-height:100svh, תוכן ממורכז לגובה וריפוד עליון בגובה ההדר; hero-fit ו-hero-vcenter מכריעים, לא הגובה של הדמו.

קוד להדבקה

הקוד כאן עומד בפני עצמו. כל טוקן עיצוב נושא ברירת מחדל, מחלקות העזר של המאגר מוטמעות בו, ותגי הסקריפט מסודרים לפי הסדר הנכון. פרויקט שמגדיר --accent או --line משלו יורש אותם אוטומטית. הרכיב הזה מסתמך על dir="rtl".

// in view = fire. Measured directly on scroll and resize, not through IntersectionObserver:
// an observer does not update while the tab is throttled (and on a real site the hero is usually
// on screen at load anyway), and an entrance that never fires leaves the hero invisible.
function inView(el,f){
  var ro;
  function chk(){
    var r=el.getBoundingClientRect();
    if(r.top<innerHeight*.9&&r.bottom>0){off();f();}
  }
  function off(){removeEventListener("scroll",chk);removeEventListener("resize",chk);if(ro)ro.disconnect();}
  addEventListener("scroll",chk,{passive:true}); addEventListener("resize",chk);
  // a layout change with no scroll (a bar above it closes, a font swaps in) can also bring it into view
  if(window.ResizeObserver){ro=new ResizeObserver(chk);ro.observe(document.body);}
  requestAnimationFrame(chk); setTimeout(chk,300);
}
function enter(root){
  var els=root.querySelectorAll(".rv");
  els.forEach(function(el,i){if(!el.style.getPropertyValue("--i"))el.style.setProperty("--i",i);});
  // a script that ran late, after the 2.5s CSS failsafe already showed the hero: keep it shown, no second entrance
  if(els.length&&getComputedStyle(els[0]).opacity==="1")root.classList.add("is-in");
  root.classList.add("rv-on");
  inView(root,function(){root.classList.add("is-in");});
}
