# הדטקטור של impeccable במאגר

נוסף ב-7.9.2026 אחרי בדיקת אבטחה מלאה. הוא לינטר עיצוב שרץ בלי LLM, בלי רשת ובלי טוקנים.

## למה סמכנו עליו

| בדיקה | תוצאה |
|---|---|
| SHA256 מול הפרסום | תואם |
| חתימה דיגיטלית | תקפה, Renaissance Geek Inc., מונפקת על ידי Microsoft, עם חותמת זמן |
| Windows Defender | ללא איומים |
| מנגנוני התמדה (Run key, schtasks, bashrc) | אפס |
| קריאות רשת ב-`detect` | אפס. הרצה עם `IMPECCABLE_API_URL` לפורט מת נתנה פלט **זהה בית לבית** |
| קוד מקור | פתוח. 61 החוקים ב-`crates/foundation/src/registry.rs` |

הטלמטריה שקיימת בכלי חיה בפקודת `craft` בלבד, מכבדת `DO_NOT_TRACK`, ולא נוגעת ב-`detect`.

## מה הוא תפס ביום הראשון

שש תקלות אמיתיות, כולן תוקנו:

| מה | היכן | לפני | אחרי |
|---|---|---|---|
| ניגודיות בצ'יפ "ממתין" | `vault.css`, **241 מופעים** | 4.30:1 | 5.83:1 |
| ניגודיות בצ'יפ קטגוריית CSS | `vault.css` (נמצא בחישוב עצמאי) | 4.21:1 | 5.47:1 |
| ניגודיות בטקסט מסלול הגלילה | `vault.css` | 1.60:1 | 5.08:1 |
| ניגודיות בפיגום הקובץ העצמאי | `portable.mjs` | 1.76:1 | 5.08:1 |
| הובר על הכפתור **הנבחר** הפך אותו ללבן על אפור בהיר, והתווית נעלמה | `.seg .fbtn:hover` גבר בספציפיות על `.fbtn.on` | 1.10:1 | תוקן עם `:not(.on)` |
| `cubic-bezier(.34,1.56,.64,1)` ב-lm3 | סותר את `motion.md` שלנו, "לעולם לא bounce" | bounce | ה-easing החתום |
| דילוג `h1` ← `h3` | **38 עמודים** | דילוג | `h2.sr-only` בתבנית העמוד |

התיקון של הכותרות נעשה בכוונה **בתבנית העמוד ולא במארקאפ של הרכיב**, כי מארקאפ הרכיב הוא
הקוד שהמאגר מייצא להדבקה בפרויקטים.

## למה החוקים האלה מושתקים

| חוק | הראיה |
|---|---|
| `em-dash-overuse` | הדפוס תופס גם `--` לפני תו לא-רווח. ב-b35 נספרו 26 "מקפים", מהם 24 בתוך `<pre>` של פאנל הקוד (`var(--line)`, `--gutter`). מקפים ארוכים אמיתיים בעמוד: **אפס**. הכלל נאכף אצלנו דרך `hebrew-writing.md` וה-hook. |
| `cramped-padding` | נורה על `.vtop` ועל `.vtoolbar`, שבהם הריפוד יושב על הילד (`.vtop-in`). |
| `clipped-overflow-container` | מקורו ב-`html,body{overflow-x:clip}`, שהוא חובה לפי `fluid-frame.md`. |
| `icon-tile-stack` | קומפוזיציה מאושרת ב-`library/sections.md` ובכרטיסי השירות של סיני. |
| `kicker-above-heading` | הקיקר הוא חלק מחוק ההירו של design-dna. |
| `numbered-section-labels` | הקיקר העריכתי-הממוספר נטבע בסיני ב-12.8.2026 לבקשת ליאב. |
| `wide-tracking` | נורה על `letter-spacing: 0.18em` שיושב על הקיקר ולא על טקסט רץ. |

`ignoreFiles` מוציא שתי תיקיות: `anti/` (עמודים שכל מטרתם להדגים עיצוב גרוע) ו-`export/`
(שכפול של אותם רכיבים, שמכפיל כל ממצא).

**מה שנשאר דלוק בכוונה**: `low-contrast`, `bounce-easing`, `skipped-heading`, `layout-transition`,
`tight-leading`, `dark-glow`, `gradient-text`, `flat-type-hierarchy`, `text-overflow`,
`broken-image`, `script-error`, `side-tab`, `marquee`.

## מה עוד פתוח

**הפלייסהולדרים.** ל-`.ph` יש `color:#fff` על שישה גרדיאנטים, ו-183 מהם נושאים תווית נראית.
בקצה הבהיר של כל ששת הגרדיאנטים הלבן נכשל ב-AA, ובשניים הוא נכשל גם בקצה הכהה:

| | קצה כהה | קצה בהיר |
|---|---|---|
| ph-a | 5.67:1 | **2.97:1** |
| ph-b | 7.12:1 | **3.36:1** |
| ph-c | 5.59:1 | **1.99:1** |
| ph-d | **4.37:1** | **1.75:1** |
| ph-e | **3.58:1** | **1.90:1** |
| ph-f | 5.46:1 | **2.32:1** |

זה הרוב המוחלט של הממצאים שנשארו. התיקון דורש להכהות שישה גרדיאנטים, וזה משנה את המראה
של כל עמוד דמו במאגר, ולכן זו החלטה של ליאב ולא תיקון מכני.

**`ignoreValues` לא עבד** בפורמט `"transition: max-width"`. 53 הממצאים שנשארו מגיעים כולם
מ-`.bpwrap` בתשתית העמוד, לא מרכיבים.

## הרצה

חשוב: מריצים **מתוך תיקיית המאגר**, אחרת הקונפיג לא מתגלה.

```bash
npx impeccable detect .
npx impeccable detect --json . > findings.json
```
