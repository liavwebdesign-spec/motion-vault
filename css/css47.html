CSS טהור CSS @property · conic-gradient · IntersectionObserver כרטיסיםרקע ואווירה ממתין

שלושה כרטיסי מנוי, והמומלץ כהה. כשהסקשן נכנס למסך, אור צבעוני רך מקיף את הקצה של הכרטיס המומלץ פעמיים, כמו כוכב שביט, מאט ונח בפינה העליונה. ריחוף מעל הכרטיס מגביר את האור ומרים אותו מעט.

מתי משתמשים: עמוד מחירים או מנויים, כדי להפנות את העין לחבילה אחת בלי תווית צועקת. כרטיס אחד בעמוד, לא יותר. מתאים לחלל עבודה, חדר כושר, תוכנה, קורס. לא בסקשן שכבר יש בו תנועה אחרת, ולא בעור שקט מאוד שבו כל אור צבעוני הוא רעש; שם מספיק הכרטיס הכהה.

שחזור. השראה: animtd.store (26.10.2026), סרטון של כרטיס תמחור שאור רץ על הקצה שלו. נבנה מאפס מהצפייה. במה זה שונה ממה שיש: css12 היא מסגרת גרדיאנט מלאה שמסתובבת בלי סוף. כאן אין מסגרת: יש ראש אור אחד עם זנב, הוא מקיף את הכרטיס פעמיים כשהסקשן נכנס למסך, מאט ונח. זה לא קו: האור הוא שתי שכבות conic-gradient מטושטשות (3 ו-22 פיקסלים) שיושבות מאחורי הכרטיס, ורואים רק את מה שבורח מהקצה, כך שהוא נקרא כהילה ולא כמסגרת (התורה אוסרת קווי מסגרת). המבנה: האור על ה-li עם isolation:isolate, והרקע על .pg-in שבתוכו. בלי העטיפה, הרמה בריחוף (transform) הייתה יוצרת הקשר ערימה חדש, והאור היה צף מעל הרקע ומכסה את הכרטיס. הסיבוב: @property --pg (זווית) מונפש מ-20 ל-740 מעלות, שני סיבובים, ב-3.6 שניות בעקומה החתומה, שמאטה לקראת הסוף. בלי JS האור נח בפינה העליונה; ה-JS רק מוסיף is-in כשהסקשן נכנס למסך. הפחתת תנועה: בלי סיבוב, האור נח. בטלפון הכרטיסים בטור, והאור זהה.

(function(){
  const root=document.querySelector("[data-pg]");
  if(!root)return;
  root.classList.add("is-live");          // בלי JS האור נח בפינה העליונה
  const go=()=>root.classList.add("is-in");
  if(!("IntersectionObserver" in window))return go();
  const io=new IntersectionObserver(es=>{if(es.some(e=>e.isIntersecting)){io.disconnect();go();}},{threshold:.4});
  io.observe(root);
})();
