CSS29 · מטאורים חולפים ברקע

CSS טהור CSS · keyframes רקע ואווירההירו ופתיחה ממתין

פסי אור דקים שחוצים את הרקע באלכסון בזמנים ומהירויות אקראיים. עשרים שניות של רקע חי בלי שום JS.

מתי משתמשים: הירו כהה של מוצר טכנולוגי, סקשן "בקרוב", עמוד 404. רק על רקע כהה, ורק אחד לעמוד.

הדמו כאן עיצובי-ניטרלי בכוונה. כשהמהלך נכנס לפרויקט, מיובאת רק ההתנהגות: הצבעים, הרדיוסים, הפונטים והצללים יורשים את העיצוב של אותו פרויקט.

מקור: MagicUI Meteors. נכתב מחדש ב-CSS בלבד: כל מטאור מקבל מיקום, השהיה ומשך ב-inline vars, כך שאין שני מטאורים זהים.

קוד להדבקה

הקוד כאן עומד בפני עצמו. כל טוקן עיצוב נושא ברירת מחדל, מחלקות העזר של המאגר מוטמעות בו, ותגי הסקריפט מסודרים לפי הסדר הנכון. פרויקט שמגדיר --accent או --line משלו יורש אותם אוטומטית.
