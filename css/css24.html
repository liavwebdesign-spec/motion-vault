CSS24 · מרקר שנמתח מאחורי מילה

CSS טהור CSS · scroll-driven טקסט וכותרות ממתין

מילה שמקבלת פס צבע מאחוריה, נמתח מימין לשמאל בזמן שהיא נכנסת למסך. בלי JS: הרקע הוא גרדיאנט שגדל, והתזמון מגיע מ-animation-timeline של הגלילה.

מתי משתמשים: הדגשת מילת מפתח במשפט פתיחה, ציטוט, הבטחה מרכזית. אחת או שתיים בעמוד, אחרת זה הופך לצבע ולא להדגשה.

הדמו כאן עיצובי-ניטרלי בכוונה. כשהמהלך נכנס לפרויקט, מיובאת רק ההתנהגות: הצבעים, הרדיוסים, הפונטים והצללים יורשים את העיצוב של אותו פרויקט.
