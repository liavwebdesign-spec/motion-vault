CSS טהור CSS grid-rows transition מאושר-עין

פתיחה וסגירה חלקות עם הטריק המודרני: grid-template-rows מ-0fr ל-1fr, בלי JS שמודד גבהים.

מתי משתמשים: שאלות ותשובות, מפרטים.

grid-template-rows עובר מ-0fr ל-1fr, והדפדפן עושה את כל העבודה.

כן, כל הדפדפנים המודרניים תומכים במעבר על fr.

הכפתור אמיתי, מקלדת עובדת, והתוכן נשאר ב-DOM.
