CSS28 · אדוות רקע מאחורי אלמנט

CSS טהור CSS · keyframes רקע ואווירההירו ופתיחה ממתין

מעגלים קונצנטריים שמתרחבים ודוהים לאט מאחורי אלמנט מרכזי, כמו אבן במים. שקט מאוד, כמעט לא מורגש, ונותן לכפתור או ללוגו נוכחות.

מתי משתמשים: מאחורי CTA ראשי, לוגו בהירו, או אייקון "זמין עכשיו". עדין מספיק כדי לשבת מאחורי טקסט.

הדמו כאן עיצובי-ניטרלי בכוונה. כשהמהלך נכנס לפרויקט, מיובאת רק ההתנהגות: הצבעים, הרדיוסים, הפונטים והצללים יורשים את העיצוב של אותו פרויקט.

הדמו

מוכנים להתחיל?

מקור: MagicUI Ripple. נכתב מחדש ב-CSS בלבד עם שמונה טבעות ב---i. השקיפות יורדת עם הרדיוס, כך שהחיצוניות כמעט לא נראות.

קוד להדבקה

הקוד כאן עומד בפני עצמו. כל טוקן עיצוב נושא ברירת מחדל, מחלקות העזר של המאגר מוטמעות בו, ותגי הסקריפט מסודרים לפי הסדר הנכון. פרויקט שמגדיר --accent או --line משלו יורש אותם אוטומטית.
