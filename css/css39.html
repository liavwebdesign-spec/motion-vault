CSS39 · שרטוט שרועד כמו קו מצויר ביד

CSS טהור CSS keyframes · SVG (שלוש גרסאות יד לכל קו) · IO תמונות וגלריותרקע ואווירה ממתין

שרטוט קווי של בית עם תוספת מוצעת בצבע המותג, על נייר מנוקד עם כותרת שרטוט קטנה. כל קו משורטט בכל פעם מחדש כאילו היד זזה: הפינות חורגות מעט, הקווים מתעקלים בעדינות, והשרטוט רועד בקצב איטי בלי שהמבנה זז. מתחת לשרטוט מקרא ״קיים״ ו״מוצע״ וכפתור קטן שמשהה את הרעידה, ובתוך השרטוט מידת התוספת. הקווים חדים בכל גודל מסך.

מתי משתמשים: סטודיו לשיפוצים, אדריכלות, עיצוב פנים, בנייה, או כל עסק שמתחיל משרטוט: הקווים הרועדים אומרים שזה עדיין נייר ואפשר לשנות. מתאים כאיור בסקשן ״איך אנחנו עובדים״ או לצד טופס פנייה. לא לצד נתונים מדויקים, כי הרעידה אומרת ״בערך״.

רואים את התוספת על הנייר לפני שמניחים בלוק ראשון

בפגישה הראשונה אנחנו משרטטים יחד את הבית כמו שהוא ואת התוספת המוצעת, כדי שתראו מה משתנה ומה נשאר.

עוד מסלול גלילה. נסה גם חזרה למעלה ↑
שחזור. השראה: כמה סרטוני שרטוט ב-prompt-motion.com (21.10.2026) שבהם קווי העט רועדים בין פריימים, מה שמכונה boil באנימציה מצויירת. נבנה מאפס מהצפייה. גרסה 2 (25.10.2026): הרעידה הקודמת באה ממסנני SVG (feTurbulence ו-feDisplacementMap), והם שברו את הקווים לפיקסלים מדורגים והיו כבדים לחישוב בכל פריים. עכשיו אין מסנן בכלל. שלוש גרסאות יד לכל קו: מחולל קטן בראש הקובץ (skSeg) מצייר כל קו ישר כעקומה אחת עם חריגה קטנה בפינות, קשת עדינה וסטייה בקצוות. חריגה וקשת קבועות לקו, והסטייה משתנה בין שלוש הגרסאות, ולכן הקו נראה כמו אותו קו שנשרטט שוב. כל גרסה היא <g class="lb-fr"> נפרד עם כל הקווים. ההחלפה היא CSS בלבד: לכל קבוצה אותו @keyframes עם steps(1,end) ו-animation-delay של שליש מחזור, כך שבכל רגע נראית קבוצה אחת בדיוק, בשבע החלפות בשנייה בערך. הקבוצה הראשונה היא ברירת המחדל במארקאפ: בלי JS ובהפחתת תנועה רואים שרטוט שלם ויציב. פועל רק כשהסקשן על המסך (is-on מ-IntersectionObserver). רעידה בלי סוף דורשת כפתור השהיה (WCAG 2.2.2): הכפתור מוסתר במארקאפ (hidden), JS מגלה אותו, והוא עוצר את האנימציה במקום (animation-play-state), בלי קפיצה. בהפחתת תנועה אין תנועה ואין כפתור. המידה והתוויות הן HTML מחוץ ל-SVG, כך שהטקסט חד בכל גודל. להחלפת האיור: מחליפים את רשימות הקווים ב-SK_GROUPS (כל קו הוא [x1, y1, x2, y2]); כדאי להשאיר כמה צורות ראשיות עבות ועוד קווי הצללה דקים (soft), כי בשרטוט מפורט הרעידה נראית כרעש. נגישות: ל-SVG יש role=img ו-aria-label, ולכפתור aria-pressed ושם שמשתנה.
