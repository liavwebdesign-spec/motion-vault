CSS39 · שרטוט שרועד כמו קו מצויר ביד

CSS טהור CSS keyframes · SVG feTurbulence + feDisplacementMap · IO תמונות וגלריותרקע ואווירה ממתין

שרטוט קווי של בית עם תוספת מוצעת בצבע המותג, שהקווים שלו רועדים קלות, כאילו כל פריים צויר מחדש בעט. הרעידה בקצב איטי של שלושה פריימים בשנייה, בלי לשנות את המבנה: הקווים נשארים במקומם ורק הקצוות זזים בשבריר. מתחת לשרטוט שתי תוויות, ״קיים״ ו״מוצע״, שנשארות יציבות וחדות.

מתי משתמשים: סטודיו לשיפוצים, אדריכלות, עיצוב פנים, בנייה, או כל עסק שמתחיל משרטוט: הקווים הרועדים אומרים שזה עדיין נייר ואפשר לשנות. מתאים כאיור בסקשן ״איך אנחנו עובדים״ או לצד טופס פנייה. לא לצד נתונים מדויקים, כי הרעידה אומרת ״בערך״.

רואים את התוספת על הנייר לפני שמניחים בלוק ראשון

בפגישה הראשונה אנחנו משרטטים יחד את הבית כמו שהוא ואת התוספת המוצעת, כדי שתראו מה משתנה ומה נשאר.

עוד מסלול גלילה. נסה גם חזרה למעלה ↑
שחזור. השראה: כמה סרטוני שרטוט ב-prompt-motion.com (21.10.2026) שבהם קווי העט רועדים בין פריימים, מה שמכונה boil באנימציה מצויירת. נבנה מאפס מהצפייה. הרעידה היא ארבעה מסנני SVG (#lb-f1 עד #lb-f4): בכל אחד feTurbulence עם seed אחר ו-feDisplacementMap בעוצמה 4, כלומר כל מסנן מזיז את הקווים בצורה אחרת. ההחלפה בין המסננים היא CSS בלבד: @keyframes שמחליף את filter:url(#id) כל רבע מחזור, עם steps(1,end) כדי שההחלפה תהיה חדה ולא מרוחה. המסנן מופעל רק כשהסקשן על המסך (is-on, מוסיף IntersectionObserver), כי מסנן שמחושב מחדש מחוץ למסך הוא בזבוז. בלי JS ובהפחתת תנועה רואים את השרטוט הנקי והיציב. התוויות הן HTML מחוץ ל-SVG, ולכן המסנן לא מזיז אותן. סידור התוויות קבוע משמאל לימין (direction:ltr), כי ה-SVG לא מתהפך ב-RTL. להחלפת האיור: מחליפים את הנתיבים של .lb-sk, וכדאי להשאיר 3 עד 6 צורות ראשיות ועוד קווי הצללה דקים (lb-soft), כי בשרטוט מפורט הרעידה נראית כרעש. נגישות: ל-SVG יש role=img ו-aria-label.

קוד להדבקה

הקוד כאן עומד בפני עצמו. כל טוקן עיצוב נושא ברירת מחדל, מחלקות העזר של המאגר מוטמעות בו, ותגי הסקריפט מסודרים לפי הסדר הנכון. פרויקט שמגדיר --accent או --line משלו יורש אותם אוטומטית. הרכיב הזה מסתמך על dir="rtl".
