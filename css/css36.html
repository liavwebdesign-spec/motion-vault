CSS36 · כתם שמשנה צורה ומהפך את המילה

CSS טהור CSS keyframes · border-radius · container units טקסט וכותרותרקע ואווירה ממתין

כתם בצבע המותג משנה את קו המתאר שלו לאט, נע ומסתובב מאחורי מילה גדולה, ובכל מקום שהכתם מכסה את האותיות הן מתהפכות לצבע הטקסט שעל המשטח. שני קווי מתאר דקים מהדהדים את הצורה בפאזה אחרת. הכול CSS, בלי JS ובלי SVG.

מתי משתמשים: כותרת הפתיחה של אתר שהמילה היא הנכס שלו: סטודיו, גלריה, מותג בוטיק, אירוע, מרצה. עובד הכי טוב עם מילה אחת קצרה וגדולה. לא לכותרת של משפט שלם ולא לאתר שצריך להרגיש רציני ושקט.

קרמיקה

סדנאות לקבוצות קטנות, כלים בהזמנה אישית וחנות עם כלי בית שנשרפו בתנור שלנו.

שחזור. השראה: כמה סרטונים ב-prompt-motion.com (21.10.2026) שבהם כתם צבעוני מתפתל מאחורי מילה, והאותיות מתהפכות בצבען במקום שהכתם עובר, עם קווי מתאר דקים סביבו. נבנה מאפס מהצפייה. ההיפוך: במקום mix-blend-mode: difference, שנותן צבעים אקראיים ולא שייכים לערכת הנושא, יש במילה עותק שני בתוך הכתם (overflow: hidden ו-border-radius חותכים אותו) בצבע var(--accent-ink). העותק עומד בדיוק מעל המילה המקורית, כי הוא מקבל את ההופכי של תזוזת הכתם: מסלול הכתם הוא translate(x,y) rotate(r) והעותק רץ באותם keyframes, אותו משך ואותו easing, עם rotate(-r) translate(-x,-y), ולכן בכל פריים הוא יושב במקום. כל שינוי במסלול הכתם חייב להיכנס לשני ה-keyframes יחד. הצורה: האנימציה של border-radius בשמונה ערכים עם אחוזים מעבירה את הכתם בין ארבע צורות, ו-alternate מחזיר אותו לאחור. יחידות: container-type: size על המסגרת ו---s: min(50cqw, 86cqh) לגודל הכתם, כך שהכתם והעותק גדלים עם המסגרת ולא יוצאים ממנה. בדפדפן בלי יחידות מכולה הכתם נעלם והמילה נשארת קריאה. הטבעות: אותו keyframe עם animation-delay שלילי וגודל גדול ב-12% וב-24%. נגישות: המילה היא כותרת אמיתית, והעותק והכתם aria-hidden. RTL: המילה במרכז והכתם ממורכז, לכן אין מה להפוך באתר LTR. בלי תנועה: animation: none והכתם נשאר בצורת הפתיחה, כשהעותק ההפוך עדיין מיושר בדיוק.
