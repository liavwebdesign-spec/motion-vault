CSS23 · מעבר מצבים חלק (View Transitions)

CSS טהור View Transitions API תמונות וגלריותכרטיסיםניווט ומבנה ממתין

החלפת תוכן בלי קפיצה: הדפדפן מצלם את המצב הישן והחדש ומנפיש ביניהם לבד. פריט שנבחר גדל למקומו החדש כי שני הצדדים חולקים אותו view-transition-name.

מתי משתמשים: מעבר מגריד לתצוגת פריט, החלפת טאבים, מיון רשימה. חלופה נטיבית ל-Flip כשלא רוצים ספרייה. בדפדפן שלא תומך התוכן פשוט מתחלף מיד, בלי שבירה.

הדמו כאן עיצובי-ניטרלי בכוונה. כשהמהלך נכנס לפרויקט, מיובאת רק ההתנהגות: הצבעים, הרדיוסים, הפונטים והצללים יורשים את העיצוב של אותו פרויקט.

לחץ על פריט ואז על חזרה. אם הדפדפן לא תומך ב-View Transitions, ההחלפה פשוט מיידית.

התמיכה: כרום ואדג' מלאה, ספארי 18 ומעלה, פיירפוקס עדיין לא. הקוד כתוב כך שהיעדר תמיכה מחליף תוכן מיד במקום להישבר, ותחת prefers-reduced-motion המעבר מבוטל.
