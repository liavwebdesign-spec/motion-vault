G230 · נקודה שנמתחת לקו, למישור ולכרטיס בפרספקטיבה

GSAP GSAP · ScrollTrigger scrub · sticky · CSS 3D תהליך ושלביםטקסט וכותרות ממתין

נקודה אחת עם טבעת שמתרחבת סביבה נמתחת לקו דק, הקו מתרחב למישור, והמישור נשכב בפרספקטיבה כשהמילה שעליו מחליקה לאורך המשטח המשופע ונשארת נטויה יחד איתו. הכול בקצב הגלילה: גוללים קדימה והצורה מתפתחת, גוללים אחורה והיא חוזרת לנקודה. ליד הצורה יושבים כותרת ופסקה שנשארות במקומן.

מתי משתמשים: פתיחה של סקשן שמסביר שיטת עבודה או תהליך: תכנון, אפיון, בנייה. הצורה אומרת שמתחילים מדבר קטן ובונים ממנו. מתאים לסטודיו, משרד הנדסה, ייעוץ או כל שירות שיש לו שיטה. פעם אחת בעמוד, בפתיחת החלק של דרך העבודה.

בונים תוכנית עבודה לפני שמניחים את הקיר הראשון

בפגישה הראשונה אנחנו מגדירים מה חשוב לכם, אחר כך מתכננים שלבים ותקציב, ורק אז יוצאים לביצוע. כך אין הפתעות באמצע.

תכנון
עוד מסלול גלילה. נסה גם חזרה למעלה ↑
שחזור. השראה: שני סרטונים ב-prompt-motion.com (21.10.2026) שבהם נקודה הופכת לקו, למישור ולכרטיס מוטה עם מילה עליו. נבנה מאפס מהצפייה. שני עטיפות לצורה: .dp-tilt מקבל רק rotationX ו-.dp-obj רק סיבוב במסך, כי GSAP מרכיב את הסיבוב בסדר קבוע (סיבוב במסך מבחוץ, הטיה פנימה) ולכן סיבוב על אותו אלמנט נראה כמו מישור שמסתובב במסך ולא כמו מישור שמוטה אחרי שסובב. הפרספקטיבה היא perspective ב-CSS על הבמה. המילה על המשטח היא ילד של המישור, כך שהיא חולקת איתו את כל ההטיה, והיא מחליקה ב-x בתוך המשטח, כלומר לאורך הכיוון המשופע. הרקע של המישור (.dp-bg) הוא האלמנט שנמתח ב-scaleX ואחר כך ב-scaleY, כדי שהמילה לא תימעך יחד איתו. הערך הסופי ב-CSS: הכרטיס המוטה עם המילה. בלי GSAP ובהפחתת תנועה רואים אותו מיד, בלי גלילה מוארכת. כשהמהלך רץ נוספת is-live, והמסלול מוארך ל-340vh עם במה נעוצה (position:sticky), כך שאפשר להגיע למצב הסופי. בטלפון הבמה נעוצה למעלה והטקסט מתחתיה. באתר משמאל לימין מחליפים את סימן ה-x של המילה ואת זווית הסיבוב. תמיד מילה אחת או כותרת קצרה על המישור.

JS

if (typeof gsap !== "undefined") gsap.registerPlugin(ScrollTrigger);

(function(){
  if(typeof gsap==="undefined"||typeof ScrollTrigger==="undefined")return;   // בלי GSAP נשאר הכרטיס המוטה (ב-CSS)
  const root=document.querySelector(".dp"),track=root.querySelector(".dp-track");
  const dot=root.querySelector(".dp-dot"),ring=root.querySelector(".dp-ring"),tilt=root.querySelector(".dp-tilt");
  const obj=root.querySelector(".dp-obj"),bg=root.querySelector(".dp-bg"),label=root.querySelector(".dp-label");
  const sgn=getComputedStyle(root).direction==="rtl"?1:-1;   // המילה נכנסת מצד תחילת הקריאה
  // בהפחתת תנועה הפונקציה לא רצה
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)",()=>{
    root.classList.add("is-live");
    gsap.set(bg,{scaleX:0,scaleY:.012});gsap.set(label,{opacity:0});
    gsap.set(tilt,{rotationX:0});gsap.set(obj,{rotation:0});
    const tl=gsap.timeline({defaults:{ease:"power2.inOut"},
      scrollTrigger:{trigger:track,start:"top top",end:"bottom bottom",scrub:.6,invalidateOnRefresh:true}});
    tl.fromTo(dot,{scale:0,opacity:0},{scale:1,opacity:1,duration:1,ease:"power2.out"},0)
      .fromTo(ring,{scale:.8,opacity:.7},{scale:3.4,opacity:0,duration:1.6,ease:"power1.out"},.5)
      .to(dot,{opacity:0,scale:.5,duration:.8},2.4)
      .to(bg,{scaleX:1,duration:2.6},2)
      .to(bg,{scaleY:1,duration:2.4},4.8)
      .to(tilt,{rotationX:58,duration:3},7.2)
      .to(obj,{rotation:-26,duration:3},7.2)
      .fromTo(label,{opacity:0,x:()=>sgn*160},{opacity:1,x:0,duration:2.2,ease:"power2.out"},8)
      .to({},{duration:1});
    return()=>{root.classList.remove("is-live");tl.scrollTrigger&&tl.scrollTrigger.kill();tl.kill();gsap.set([dot,ring,bg,label,tilt,obj],{clearProps:"all"});};
  });
})();
