G270 · שבבים שעולים מלמטה ונערמים לערימה

GSAP GSAP · ScrollTrigger · stagger כרטיסיםטעינה ופידבק ממתין

שבבים קטנים בגוונים שונים עולים מהקצה התחתון של הכרטיס בגלים, ומתיישבים בשורות רופפות שחופפות זו לזו. כל גל מוסיף שורה, הערימה גדלה, והמספר שמעליה עולה יחד איתה עד הסך הכול. בסוף נשארת ערימה אחת שמראה כמה דברים יש בפנים.

מתי משתמשים: סקשן יכולות או שירותים עם הרבה פריטים קצרים: עשרים עד שלושים סוגי עבודות, כלים, טכנולוגיות, תחומי התמחות. הערימה מראה את הכמות, והרשימה נשארת טקסט אמיתי שאפשר לקרוא. לא עם שלושה פריטים, ולא כשכל פריט צריך הסבר.

עוד מסלול גלילה. נסה גם חזרה למעלה ↑
שחזור. השראה: כמה סרטונים בגלריה של prompt-motion.com (21.10.2026) שבהם שבבים או כרטיסים קטנים עולים בגלים מתחתית המסך ומצטברים לערימה. נבנה מאפס מהצפייה. המארקאפ הוא המצב הסופי: ארבע שורות (.hp-row) בצורת פירמידה, 9, 7, 5 ו-3 שבבים, ולכל שבב סיבוב והזזה קלים במאפייני rotate ו-translate של CSS לפי nth-child, כך שהערימה נראית רופפת בלי לחשב מיקומים. בלי GSAP ובהפחתת תנועה זה מה שרואים. זו רשימה אמיתית: הפריטים הם li בתוך ul, ולכן קורא מסך שומע את כל התחומים, והמספר הרץ מוסתר ומוחלף בטקסט נסתר. כשהמהלך רץ timeline אחד מעלה את השורות מהתחתונה כלפי מעלה: כל שבב עולה מתחת לקצה הכרטיס (overflow:hidden חותך אותו), מסתובב ומתיישב ב-power3.out, והמספר סופר מאפס ל-24 לאורך כל ה-timeline באותו קצב. ה-timeline מתחיל כשהכרטיס מגיע ל-65% מהמסך ומתאפס כשחוזרים מעליו, כך שאפשר לראות אותו שוב. לקצב גלילה מוסיפים scrub ל-ScrollTrigger ונעצים את הכרטיס. ארבע שורות במקום פיזיקה: מיקום קבוע קורא טוב יותר ועולה פחות ממנוע פיזיקה כמו matter.js. ערימה שנופלת באמת צריכה קנבס. צבעים: שלושה גוונים מטוקני העור (accent, גוון בהיר שלו ו-bg), ובפרויקט מחלקים אותם לפי קטגוריה אמיתית. גדלים: כל שבב הוא padding ו-font-size בלבד, ולכן שורה ארוכה נשברת לשתיים בטלפון והערימה פשוט נעשית גבוהה יותר. כיווניות: סדר השבבים בשורה נקבע לפי כיוון הדף, ואין מה להחליף באתר LTR.

JS

if (typeof gsap !== "undefined") gsap.registerPlugin(ScrollTrigger);

(function(){
  if(typeof gsap==="undefined")return;      // בלי GSAP הערימה והמספר כבר במצב הסופי (במארקאפ)
  const root=document.querySelector(".hp"),num=root.querySelector(".hp-count b");
  const total=parseInt(num.textContent,10)||0;
  // בהפחתת תנועה הפונקציה לא רצה
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)",()=>{
    const rows=[...root.querySelectorAll(".hp-row")].reverse();      // התחתונה עולה ראשונה
    const o={n:0},draw=()=>{num.textContent=Math.round(o.n);};
    const tl=gsap.timeline({paused:true});
    rows.forEach((row,wi)=>{
      tl.fromTo(row.children,{y:340,autoAlpha:0,rotation:()=>gsap.utils.random(-28,28)},
        {y:0,autoAlpha:1,rotation:0,duration:.9,ease:"power3.out",stagger:{each:.05,from:"random"}},wi*.5);
    });
    tl.fromTo(o,{n:0},{n:total,duration:tl.duration(),ease:"none",onUpdate:draw,immediateRender:false},0);
    draw();
    // הגלים מתחילים כשהכרטיס מגיע ל-65% מהמסך, ומתאפסים כשחוזרים מעליו. טעינה אחרי הכרטיס (שחזור גלילה) מציגה את הערימה גמורה
    ScrollTrigger.create({trigger:root,start:"top 65%",onEnter:()=>tl.play(),onLeaveBack:()=>{tl.pause(0);draw();},
      onRefresh:s=>{if(s.progress>=1&&tl.progress()<1){tl.progress(1);draw();}}});
    return()=>{num.textContent=total;gsap.set(root.querySelectorAll(".hp-c"),{clearProps:"all"});};
  });
})();
