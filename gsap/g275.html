תמונה גדולה נכנסת מימין ונעצרת במרכז הבמה, ומאחוריה נמתחים אחריה כמה עשרות פסים דקים לרוחב המסך. בתחילה הפסים ארוכים, וככל שהתמונה מאטה הם מתקצרים עד שנשארים מהם קצוות קצרים. מאחורי הכל מילה ענקית בקו מתאר זזה לאט באותו כיוון.

מתי משתמשים: פתיח או סקשן אודות של עסק שעוסק בתנועה: השכרת רכבים, שליחויות, ספורט, נסיעות. הסצנה נעוצה ודורשת מסלול גלילה, ולכן היא מתאימה לעמוד נחיתה או לסקשן אחד בולט, פעם אחת. צריך תמונה חזקה אחת שעומדת בפני עצמה.

ואן מוכן לטיול, מהאיסוף ועד ההחזרה

מקבלים רכב נקי עם ציוד קמפינג מלא ומסלולים מוכנים, ומחזירים בכל אחד מהסניפים.

בדרך
עוד מסלול גלילה. נסה גם חזרה למעלה ↑
שחזור. השראה: סרטון ב-prompt-motion.com (21.10.2026) שבו קווים אופקיים דקים חולפים במהירות מאחורי דמות שדוהרת, עם מילה ענקית בקו מתאר ברקע. נבנה מאפס מהצפייה. סצנה נעוצה אחת: .sl גבוה (260svh) וב-.sl-pin נעוץ בו (position:sticky), וטיימליין אחד מקושר לגלילה (scrub) מפעיל הכל. הקשר בין המהירות לאורך הפס: התמונה נעה ב-power1.out, ומהירות בעקומה כזו יורדת ליניארית, ולכן אורך הפסים יורד ב-ease:none. כך הפס תמיד ארוך כפי שהתנועה מהירה, ולכל פס משך משלו (62% עד 90% מהטיימליין), כך שהם מתיישבים בזמנים שונים. הפסים הם ילדים של התמונה: הם נעים איתה ויוצאים מהקצה הימני שלה, מאחוריה. הרוחב הסופי הוא זנב קצר (--v, בין 16 ל-80 פיקסלים) שמתחיל בצבע מלא ודועך, וזה מה שרואים בלי GSAP ובהפחתת תנועה: תמונה במרכז וקצוות קצרים שיוצאים ממנה. ה-JS מחשב מכל זנב את scaleX ההתחלתי לפי data-g (אורך נוסף ב-vw) ומחשב מחדש בשינוי גודל (invalidateOnRefresh). פסי רקע: שמונה פסים נוספים (.sl-ghost) חולפים מימין לשמאל על פני כל הבמה, מאחורי התמונה והמילה, במהירות קבועה ובזמנים שונים, ויוצאים מהמסך לפני שהתמונה נעצרת. הם מוצגים רק כשהמהלך חי (המחלקה is-live), ולכן בלי GSAP ובהפחתת תנועה הם לא קיימים בכלל. המילה (.sl-word) זזה 8% לכל כיוון, לאט מהתמונה, כדי שהעומק ייראה. כיוון: התנועה מימין לשמאל והפסים נמתחים לימין, כלומר מאחורי הנושא. באתר משמאל לימין מחליפים left ב-right בפסים, transform-origin ל-100% 50%, ומהפכים את הסימן של x ושל xPercent ב-JS. בטלפון התמונה צרה יותר (76vw), הכותרת קצרה יותר והסצנה נעוצה באותו אופן. נגישות: הפסים והמילה aria-hidden, והתוכן האמיתי הוא הכותרת, הפסקה והתמונה עם ה-alt שלה.

JS

if (typeof gsap !== "undefined") gsap.registerPlugin(ScrollTrigger);

(function(){
  if(typeof gsap==="undefined")return;      // בלי GSAP התמונה במרכז וקצוות הפסים קצרים (במארקאפ)
  const root=document.querySelector(".sl"),track=root.querySelector(".sl-track"),subj=root.querySelector(".sl-subject"),word=root.querySelector(".sl-word"),lines=gsap.utils.toArray(".sl-lines i",root),ghosts=gsap.utils.toArray(".sl-ghost i",root);
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)",()=>{
    const half=()=>subj.offsetWidth/2;
    const GS=[.02,.12,0,.2,.07,.16,.04,.1],GD=[.62,.55,.7,.5,.66,.58,.72,.6];     // התחלה ומשך של כל פס רקע, בחלקי הטיימליין
    root.classList.add("is-live");
    const tl=gsap.timeline({defaults:{ease:"none"},scrollTrigger:{trigger:root,start:"top top",end:"bottom bottom",scrub:.6,invalidateOnRefresh:true}});
    // התמונה נכנסת מימין ומאטה. מהירות בעקומה הזו יורדת ליניארית, ולכן אורך הפסים יורד ב-ease:none
    tl.fromTo(subj,{x:()=>track.offsetWidth/2+half()*1.1},{x:0,duration:1,ease:"power1.out"},0);
    tl.fromTo(word,{xPercent:8},{xPercent:-8,duration:1},0);
    // פסי הרקע חולפים מימין לשמאל על פני כל הבמה במהירות קבועה, ויוצאים לפני שהתמונה נעצרת
    ghosts.forEach((el,i)=>{
      tl.fromTo(el,{x:()=>track.offsetWidth},{x:()=>-el.offsetWidth-40,duration:GD[i],ease:"none"},GS[i]);
    });
    lines.forEach((el,i)=>{
      const v=parseFloat(el.style.getPropertyValue("--v")),g=parseFloat(el.dataset.g);
      tl.fromTo(el,{scaleX:()=>(v+g*window.innerWidth/100)/v},{scaleX:1,duration:.62+(i%6)*.056},0);
    });
    return()=>{root.classList.remove("is-live");gsap.set([subj,word,...lines,...ghosts],{clearProps:"transform"});};
  });
})();
