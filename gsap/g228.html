G228 · שם מותג שמתחדד מטשטוש תנועה וטבעת שעוברת עליו

GSAP GSAP · SVG feGaussianBlur · ScrollTrigger (replay) הירו ופתיחהטקסט וכותרות ממתין

השם נכנס מטושטש לרוחב, כאילו הוא עובר מהר מדי לעין, ומתחדד לאותיות חדות בזמן שטבעת דקה עם זוהר חולפת מעליו מימין לשמאל. אחרי שהטבעת יוצאת, השורה התחתונה עולה, והשם נשאר חד. הטשטוש כיווני: רק אופקי, בלי רפרוף אנכי.

מתי משתמשים: פתיחה של עמוד נחיתה למותג עם שם קצר וחזק, מסך תודה, או כותרת של קמפיין. עובד כשהשם הוא הנכס עצמו ואין סמל נפרד. פעם אחת בעמוד, ולא על כותרות רגילות (לשם יש את css05 ו-css30).

אופק

הנהלת חשבונות לעסקים קטנים

עוד מסלול גלילה. נסה גם חזרה למעלה ↑
שחזור. השראה: סרטוני לוגו ב-prompt-motion.com (21.10.2026) שבהם אותיות המותג מטושטשות בתנועה ומתחדדות בזמן שטבעת אור סורקת אותן. נבנה מאפס מהצפייה. הטשטוש הכיווני הוא פילטר SVG אחד (feGaussianBlur עם stdDeviation של שני ערכים: אופקי, ואפס אנכי) ש-GSAP מחליק מ-46 ל-0 עם ה-attr plugin. הפילטר מופעל על המילה רק בזמן המהלך (set בהתחלה ו-clearProps בסוף), כך שהמילה הסופית לא עוברת דרך פילטר בכלל והטקסט חד בכל מסך. אזור הפילטר מורחב (x=-30%, width=160%) כדי שהטשטוש לא ייחתך בקצוות. הטבעת היא אלמנט CSS רגיל (border וצל), לא SVG, ונעה ב-x על רוחב המילה, שנמדד בזמן ההרצה, בלי ערך קשיח. הערך הסופי במארקאפ: המילה חדה, הטבעת בשקיפות 0. בלי GSAP ובהפחתת תנועה רואים את המצב הסופי. באתר משמאל לימין הופכים את הכיוון של הטבעת (מ-x חיובי ל-x שלילי). לא לשים על טקסט קריאה: מילה אחת עד שלוש.

הקוד כאן עומד בפני עצמו. כל טוקן עיצוב נושא ברירת מחדל, מחלקות העזר של המאגר מוטמעות בו, ותגי הסקריפט מסודרים לפי הסדר הנכון. פרויקט שמגדיר --accent או --line משלו יורש אותם אוטומטית.

JS

if (typeof gsap !== "undefined") gsap.registerPlugin(ScrollTrigger);

(function(){
  if(typeof gsap==="undefined"||typeof ScrollTrigger==="undefined")return;   // בלי GSAP המילה חדה והטבעת שקופה (במארקאפ)
  const root=document.querySelector(".rs"),word=root.querySelector(".rs-word"),ring=root.querySelector(".rs-ring"),tag=root.querySelector(".rs-tag");
  const blur=root.querySelector("#rs-blur feGaussianBlur"),W=()=>word.offsetWidth;
  // בהפחתת תנועה הפונקציה לא רצה
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)",()=>{
    const tl=gsap.timeline({paused:true});
    tl.set(word,{filter:"url(#rs-blur)"},0)
      .fromTo(blur,{attr:{stdDeviation:"46 0"}},{attr:{stdDeviation:"0 0"},duration:1.4,ease:"power3.out"},0)
      .fromTo(word,{opacity:0,scale:1.06},{opacity:1,scale:1,duration:.7,ease:"power2.out"},0)
      .fromTo(ring,{x:()=>W()*.75,scale:.55},{x:()=>-W()*.75,scale:1.15,duration:1.5,ease:"power2.inOut"},.05)
      .fromTo(ring,{opacity:0},{opacity:1,duration:.3,ease:"none"},.05)
      .to(ring,{opacity:0,duration:.45,ease:"none"},1.1)
      .fromTo(tag,{y:10,opacity:0},{y:0,opacity:1,duration:.8,ease:"power3.out"},1.25)
      .set(word,{clearProps:"filter,transform,opacity"})
      .set(tag,{clearProps:"transform,opacity"});
    const st=ScrollTrigger.create({trigger:root,start:"top 72%",end:"bottom 12%",
      onEnter:()=>tl.invalidate().restart(),onEnterBack:()=>tl.invalidate().restart(),onLeaveBack:()=>tl.pause(0)});
    return()=>{st.kill();tl.progress(1).kill();blur.setAttribute("stdDeviation","0 0");word.style.filter="";};
  });
})();
