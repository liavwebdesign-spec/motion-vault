G263 · צורות גיאומטריות שנכנסות להרכב

GSAP GSAP · ScrollTrigger scrub · SVG · sticky תמונות וגלריותרקע ואווירה ממתין

לוח ריבועי אחד ובו הרכב בסגנון באוהאוס: עיגול גדול בצבע המותג, משולש כהה, פס מוטה, נקודה, ריבוע קטן וקרן עיגול בפינה. כשגוללים כל צורה נכנסת מקצה אחר של הלוח ונעצרת במקומה, אחת אחרי השנייה, ולבסוף רשת של 16 ריבועים קטנים נבנית בפינה.

מתי משתמשים: אודות או סיפור מותג של סטודיו עיצוב, אדריכלות או מיתוג, שהשפה שלו היא צורות וגרפיקה. הצבעים לקוחים מהמותג, ולכן ההרכב משתנה עם הפלטה. לא לעסק שקט שנשען על תמונות ואנשים. פעם אחת בעמוד.

עיצוב שמתחיל מצורות פשוטות

כל מותג שאנחנו בונים מתחיל מכמה צורות בסיס. מהן מגיעים לסימן, לצבעים ולאותיות, ואחר כך לכל מה שהעסק מדפיס או מעלה לרשת.

לצפייה בעבודות
עוד מסלול גלילה. נסה גם חזרה למעלה ↑
שחזור. השראה: סרטון אחד בגלריה של prompt-motion.com (21.10.2026) שבו עיגול, משולש, פס ונקודה בצבעים ראשוניים גולשים מקצוות המסך, ננעלים בהרכב של באוהאוס, ולצידם רשת אריחים כחולה שנבנית. נבנה מאפס מהצפייה, עם טוקנים של המותג במקום אדום, צהוב וכחול. המארקאפ הוא ההרכב המלא: SVG אחד (viewBox של 100 על 100) שבו כל צורה נושאת data-from עם ההיסט שממנו היא נכנסת (x, y ביחידות הלוח). בלי GSAP ובהפחתת תנועה רואים את הלוח השלם. כשהמהלך רץ נוסף is-live: הסקשן מקבל גובה של 240svh עם שכבה דביקה אחת, וטיימליין אחד בסקראב מכניס כל צורה מההיסט שלה ב-power3.out בהפרש של 0.28, ולבסוף 16 האריחים עולים מגודל אפס בסדר אקראי (גודל האפס נקבע ב-gsap.set לפני הטיימליין, כי ב-stagger רק האריח הראשון מקבל את מצב ההתחלה מראש). הפס המוטה יושב בתוך g עם הסיבוב הקבוע שלו, והאנימציה מזיזה את הפס עצמו, כך שניקוי הסגנונות בסוף לא מוחק את הזווית. צבעים: העיגול והאריחים הראשיים ב---accent, המשולש, הנקודה והריבוע ב---ink, והפס וקרן העיגול בתערובות עם --card, כך שגם בעור חד-גוני הצורות נשארות נפרדות. בטלפון הלוח למעלה והטקסט מתחתיו, בתוך מסך אחד נעוץ. RTL: הצורות נכנסות משמאל ומלמעלה, והלוח בצד הסוף. באתר LTR מחליפים את סימן ה-x בערכי data-from. נגישות: הלוח aria-hidden, וההסבר בטקסט רגיל.

JS

if (typeof gsap !== "undefined") gsap.registerPlugin(ScrollTrigger);

(function(){
  if(typeof gsap==="undefined")return;      // בלי GSAP רואים את הלוח השלם
  const root=document.querySelector(".bh"),shapes=[...root.querySelectorAll("[data-from]")],tiles=[...root.querySelectorAll(".bh-t")];
  // בהפחתת תנועה הפונקציה לא רצה, וההרכב נשאר שלם
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)",()=>{
    root.classList.add("is-live");
    gsap.set(tiles,{scale:0,transformOrigin:"50% 50%"});      // האריחים מתחילים מגודל אפס, והטיימליין רק מגדיל אותם
    const tl=gsap.timeline({scrollTrigger:{trigger:root,start:"top top",end:"bottom bottom",scrub:.6,invalidateOnRefresh:true}});
    shapes.forEach((el,i)=>{
      const f=el.getAttribute("data-from").split(",").map(Number);
      tl.from(el,{x:f[0],y:f[1],duration:1,ease:"power3.out"},i*.28);      // כל צורה נכנסת מקצה אחר של הלוח
    });
    tl.to(tiles,{scale:1,duration:.5,ease:"power2.out",stagger:{each:.05,from:"random"}},shapes.length*.28)
      .to({},{duration:.4});      // עצירה בסוף, כדי שההרכב השלם יישאר רגע על המסך
    return()=>{root.classList.remove("is-live");gsap.set(shapes.concat(tiles),{clearProps:"all"});};
  });
})();
