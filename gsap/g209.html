G209 · משפט שנבנה מתגיות גלולה שנכנסות אחת אחרי השנייה

GSAP GSAP · ScrollTrigger · expo.out טקסט וכותרותתהליך ושלבים ממתין

משפט הצעה אחד שחלק ממילותיו הן גלולות צבעוניות. בכניסה למסך המילים הרגילות מופיעות והגלולות קופצות פנימה אחת אחרי השנייה, מימין לשמאל, וכל אחת מביאה מתחתיה שורה קטנה של פרט. בסוף מתווספת הערת אגב בנטייה מתחת למשפט.

מתי משתמשים: סיכום שירות או הצעת ערך שאפשר לומר במשפט אחד עם ארבעה עד שישה מונחים שחשוב שיזכרו. סקשן הירו משני, שירותים, או "איך אנחנו עובדים". עובד גם באתר שקט. פעם אחת בעמוד. לא למשפט ארוך, ולא כשלכל מונח אין פרט שמלווה אותו.

עוד מסלול גלילה. נסה גם חזרה למעלה ↑
שחזור. השראה: כמה סרטונים בגלריה של prompt-motion.com (21.10.2026) שבהם משפט בנוי מגלולות צבעוניות שנכנסות אחת אחת. נבנה מאפס מהצפייה. המארקאפ: משפט אחד ב-flex עם wrap, שבו מילה רגילה היא .pc-w וגלולה היא .pc-c (הגלולה .pc-p ומתחתיה small עם הפרט). בלי GSAP ובהפחתת תנועה רואים את המשפט המלא. יישור: למילה הרגילה אותו ריווח אנכי כמו לגלולה, ולכן קו הבסיס זהה ואין קפיצה בין סוגי הפריטים. הכניסה: סדר ה-DOM הוא סדר הקריאה, ולכן הכניסה מימין לשמאל. כל פריט נכנס חמישית שנייה אחרי הקודם: גלולה עם scale מ-.55, y וקפיצה ב-expo.out (בלי back, שאסור), מילה רגילה עם y קטן. הפרט שמתחת לגלולה נכנס מאוחר יותר. הצבעים: accent, ink ושלושה גוונים שנגזרים מהם ב-color-mix, וטקסט על accent ב---accent-ink. באתר משמאל לימין אין מה להפוך: הסדר עוקב אחרי ה-DOM. נגישות: המשפט נקרא כרגיל, והפרטים קטנים אבל חלק מהטקסט.

קוד להדבקה

הקוד כאן עומד בפני עצמו. כל טוקן עיצוב נושא ברירת מחדל, מחלקות העזר של המאגר מוטמעות בו, ותגי הסקריפט מסודרים לפי הסדר הנכון. פרויקט שמגדיר --accent או --line משלו יורש אותם אוטומטית. הרכיב הזה מסתמך על dir="rtl".

JS

if (typeof gsap !== "undefined") gsap.registerPlugin(ScrollTrigger);

(function(){
  if(typeof gsap==="undefined")return;      // בלי GSAP המשפט כבר מוצג עם כל הגלולות
  const root=document.querySelector(".pc"),items=[...root.querySelectorAll(".pc-w,.pc-c")],aside=root.querySelector(".pc-a");
  // בהפחתת תנועה הפונקציה לא רצה, והמשפט נשאר במצב הסופי
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)",()=>{
    const tl=gsap.timeline({paused:true});
    items.forEach((it,i)=>{
      const chip=it.classList.contains("pc-c"),body=chip?it.querySelector(".pc-p"):it;
      // הגלולה קופצת פנימה ב-expo.out, ללא overshoot. המילה הרגילה רק עולה ומתבהרת
      tl.fromTo(body,chip?{opacity:0,scale:.55,y:26,transformOrigin:"50% 60%"}:{opacity:0,y:14},
        chip?{opacity:1,scale:1,y:0,duration:.75,ease:"expo.out"}:{opacity:1,y:0,duration:.5,ease:"power2.out"},i*.2);
      if(chip)tl.fromTo(it.querySelector("small"),{opacity:0,y:8},{opacity:1,y:0,duration:.5,ease:"power2.out"},i*.2+.4);
    });
    tl.fromTo(aside,{opacity:0,y:14},{opacity:1,y:0,duration:.7,ease:"power2.out"},">-.1");
    const st=ScrollTrigger.create({trigger:root,start:"top 80%",once:true,onEnter:()=>tl.play()});
    const clear=[...items,aside,...root.querySelectorAll(".pc-p,.pc-c small")];
    return()=>{st.kill();tl.kill();gsap.set(clear,{clearProps:"opacity,transform"});};
  });
})();
